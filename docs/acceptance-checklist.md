# Чек-лист приёмки — Verde Marea

Сверяется с `spec.md`, разделы 10 и 10а (версия 2). Перед ручной проверкой: `npm run db:deploy && npm run db:seed`, приложение запущено (`npm run start:local` → http://localhost:3010). Демо-аккаунты и пароли — README, «Демо-аккаунты» (значения из `.env.example`).

Автоматически покрывается: `npm run check:rules` (правила БД и матрица ролей) и `npm run check:http` (сквозной HTTP-сценарий). Пункты с пометкой **[auto]** проверяются этими командами; руками их стоит повторить после изменений в соответствующем контуре (`AGENTS.md`).

## 0. Сборка и база

- [ ] `npm run typecheck`, `npm run lint`, `npm run build` — без ошибок.
- [ ] `npm run db:deploy` на пустой базе применяет все четыре миграции; `npm run db:status` — «Database schema is up to date».
- [ ] `prisma migrate diff --from-migrations … --to-schema-datamodel …` — «No difference detected».
- [ ] `npm run db:seed` дважды подряд — без ошибок, второй раз пишет «демо-бронирования уже были». **[auto: seed-раздел check:rules]**
- [ ] `npm run check:rules` — «122 из 122». `npm run check:http` — «24 из 24».

## 3а. План зала (версия 2, spec 10а; design 4б)

- [ ] Полоса окон дня: у каждого окна «N свободно» (или «автоподбор», если на плане подходящих нет); активное окно подчёркнуто индикатором, который переезжает между окнами. **[auto: check:http, check:rules — число = free на плане]**
- [ ] SVG-план: зал слева (бар, открытая кухня, вход), веранда справа, окна к морю, полоса моря; столы не пересекаются. **[auto: check:rules — раскладка]**
- [ ] Статусы совпадают с базой: свободен (зелёная обводка), занят (штриховка), не подходит (бледный, вне `guests…guests + 2`), недоступен (окно закрыто/началось или у вас уже есть бронь). **[auto: check:rules]**
- [ ] Клик по свободному столу → карточка (≥ 1024 px справа, уже — нижний лист): код, зона, места, время, «Забронировать этот стол», «Выбрать другой». **[auto: check:http]**
- [ ] «Забронировать этот стол» создаёт `pending` именно на выбранный стол. **[auto]**
- [ ] Стол заняли между показом и кликом — «Этот стол только что заняли… План обновлён», стол заштрихован. **[auto: check:http, check:rules — гонка]**
- [ ] Клавиатура: Tab только по свободным столам, Enter — выбор (фокус на кнопке карточки), Esc — снять выбор (фокус обратно на стол). Скринридер читает «Стол T3, зал, 4 места, свободен».
- [ ] 375 px: план повёрнут вертикально, без горизонтальной прокрутки.
- [ ] Смена окна: цвета столов меняются плавно, изменившиеся столы «вспыхивают»; у выбранного стола пульсирует золотое кольцо. При «уменьшении движения» — без анимаций.

## 8. Интерфейс

- [ ] Шрифты Cormorant Garamond (заголовки) и Manrope (текст), цвета только из `design.md`, радиусы 4/8 px, без градиентов и теней кроме карточки.
- [ ] Ширина 375 px: нет горизонтальной прокрутки ни на одной странице, таблицы превращаются в карточки с подписями полей.
- [ ] Фокус с клавиатуры — зелёная обводка у всех кнопок, ссылок и полей.
- [ ] Главная (design 4б): инерционная прокрутка (не на телефоне), заголовок по строкам из-под маски, фото «Кухня и зал» проявляются снизу вверх с параллаксом, бегущая строка (пауза при наведении), счётчики 90 / 14 / 8. Без мерцания текста до загрузки скриптов.
- [ ] Системная настройка «уменьшить движение»: на главной и в плане всё статично, текст и фото видны сразу.
