# Чек-лист приёмки — Verde Marea

Сверяется с `spec.md`, раздел 10. Перед ручной проверкой: `npm run db:deploy && npm run db:seed`, приложение запущено (`npm run start:local` → http://localhost:3010). Демо-аккаунты и пароли — README, раздел 2 (значения из `.env.example`).

Автоматически покрывается: `npm run check:rules` (правила БД и матрица ролей) и `npm run check:http` (сквозной HTTP-сценарий). Пункты с пометкой **[auto]** проверяются этими командами; руками их стоит повторить после изменений в соответствующем контуре (`AGENTS.md`).

## 0. Сборка и база

- [ ] `npm run typecheck`, `npm run lint`, `npm run build` — без ошибок.
- [ ] `npm run db:deploy` на пустой базе применяет все три миграции; `npm run db:status` — «Database schema is up to date».
- [ ] `prisma migrate diff --from-migrations … --to-schema-datamodel …` — «No difference detected».
- [ ] `npm run db:seed` дважды подряд — без ошибок, второй раз пишет «демо-бронирования уже были». **[auto: seed-раздел check:rules]**
- [ ] `npm run check:rules` — «108 из 108». `npm run check:http` — «21 из 21».

- [ ] Регистрация с новой почтой → попадаем на `/book`, в шапке «Мои бронирования» и «Выйти». **[auto]**
- [ ] Повторная регистрация на ту же почту — «Эта почта уже зарегистрирована». **[auto: check:rules]**
- [ ] В базе у нового пользователя `role = user`, `passwordHash` начинается с `$2b$12$`. **[auto]**
- [ ] Cookie `vm_session` — HttpOnly, SameSite=Lax. **[auto]**
- [ ] Неверный пароль — «Неверная почта или пароль». Выход → старая cookie больше не действует. **[auto]**
- [ ] В исходном коде страниц (Ctrl+U) нет `passwordHash` и `$2b$`. **[auto]**
